# 南京审计大学及国家审计学院简介

## 一、南京审计大学概况

南京审计大学（Nanjing Audit University）是我国唯一以"审计"命名的全日制普通本科院校，由教育部、财政部、审计署和江苏省人民政府"三部一省"共建。学校前身为1983年创建的南京财贸学院，1987年升格为本科院校并更名为南京审计学院，2015年更名为南京审计大学。

学校现有浦口和莫愁两个校区，占地面积约2000余亩，设有17个专业学院（教学部），涵盖经济学、管理学、法学、文学、理学、工学、艺术学等学科门类。学校拥有多个国家级一流本科专业建设点，审计学、会计学、金融学、工商管理等专业在全国享有较高声誉。

### 办学特色

南京审计大学以审计为品牌、经管法为主体、多学科协调发展，形成了鲜明的办学特色。学校是我国审计高等教育的重要基地，为国家审计事业培养了大量专业人才，被誉为"审计系统的黄埔军校"。

### 学科建设

学校拥有应用经济学、工商管理、统计学等一级学科硕士学位授权点，以及审计、会计、金融等专业硕士学位授权点。审计学学科在全国处于领先地位，设有审计学、会计学、财务管理等国家级特色专业。

## 二、国家审计学院介绍

国家审计学院是南京审计大学最具特色的学院之一，承担着为国家审计事业培养高素质专业人才的重要使命。

### 专业设置

学院本科教育涵盖以下方向：

| 专业方向 | 培养目标 |
|---------|---------|
| 审计学（常规方向） | 培养具备审计、会计、法律等综合知识的审计专业人才 |
| 审计学（IAEP方向） | 国际内部审计教育合作项目，培养具有国际视野的内部审计人才 |
| 审计学（政府审计方向） | 面向政府审计机关，培养公共部门审计专业人员 |
| 审计学（内部审计方向） | 面向企事业单位，培养内部控制与风险管理人才 |
| 审计学（政府审计大数据方向） | 结合大数据技术，培养新型审计技术人才 |

### 培养目标

各专业致力于"服务于地方经济建设，服务于国家审计，适应社会需求"，向社会各界输送业务骨干，培养具备健全人格和卓越素养、拥有专业化技能和国际化视野的审计与内部控制职业精英。

### 硕士研究生教育

学院设有审计专业硕士（MAud）项目，招收全日制和非全日制研究生，研究方向包括政府审计、内部审计、注册会计师审计、审计信息化等。
