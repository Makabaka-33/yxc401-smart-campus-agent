# 审计法规与准则公开资料摘要

## 一、中华人民共和国审计法

### 概述

《中华人民共和国审计法》于1994年8月31日第八届全国人民代表大会常务委员会第九次会议通过，2006年第一次修订，2021年10月23日第十三届全国人民代表大会常务委员会第三十一次会议第二次修订，自2022年1月1日起施行。

### 章节结构与核心内容

**第一章 总则（第1至6条）**

阐明立法目的，旨在加强审计监督、维护经济秩序与推进廉政建设。明确构建集中统一的审计监督体系，要求各级政府向同级人大常委会提交审计工作报告。保障审计机关依法独立行使审计监督权，强调审计人员需客观公正并保守秘密。

**第二章 审计机关和审计人员（第7至17条）**

规定审计署及地方各级审计机关的设立与双重领导体制。要求建设高素质专业化审计队伍，允许聘请外部专家。确立利益冲突时的回避机制，严禁干预企业正常经营，严格保护国家秘密、个人隐私和个人信息。

**第三章 审计机关职责（第18至33条）**

界定审计监督范围，包括政府预算执行、中央银行、国有企业、公共工程及社会保障基金等。明确管辖权划分原则，要求被审计单位建立健全内部审计制度，赋予审计机关核查社会审计机构报告质量的权力。发现重大风险隐患需及时向本级人民政府报告。

**第四章 审计机关权限（第34至41条）**

授权审计机关获取财务数据和电子数据，政务信息系统应按规定开放。经批准可查询被审计单位在金融机构的账户，对违规资产可申请法院予以冻结。允许向社会公布审计结果，并可提请公安、税务等部门予以协助。

**第五章 审计程序（第42至46条）**

规范审计工作流程，审计组需提前送达审计通知书。审计报告报送前必须征求被审计单位意见。审计决定自送达之日起生效，上级审计机关若发现下级审计决定违规，可直接作出变更或撤销的决定。

**第六章 法律责任（第47至57条）**

针对拒绝配合审计、隐匿或销毁资料等行为设定警告直至刑事追责。对违规财政收支可责令限期退还违法所得。强制要求被审计单位整改并将整改结果纳入干部考核。严惩打击报复行为及审计人员的滥用职权、徇私舞弊行为。

**第七章 附则（第58至60条）**

明确领导干部经济责任审计和自然资源资产离任审计适用本法。军队审计由中央军事委员会规定，建立军地联合审计机制。

## 二、国家审计准则

### 概述

《中华人民共和国国家审计准则》由审计署发布，是规范国家审计机关和审计人员实施审计业务的基本规范。国家审计准则体系包括基本准则、通用审计准则和专业审计准则三个层次。

### 核心要求

国家审计准则对审计全过程提出规范要求，主要包括：审计计划管理、审计实施方案编制、审计证据获取、审计工作底稿编制、审计报告撰写、审计决定执行以及审计整改跟踪等环节。准则强调风险导向审计理念，要求审计人员保持职业怀疑态度，合理运用职业判断。

## 三、中国注册会计师审计准则

### 概述

中国注册会计师审计准则由中国注册会计师协会制定、财政部批准发布，是注册会计师执行财务报表审计业务的强制性规范。现行准则体系包括：

| 类别 | 主要内容 |
|------|---------|
| 基本准则 | 审计目标和一般原则、职业道德、质量控制 |
| 具体准则 | 审计计划、风险评估、审计证据、审计报告等 |
| 实务指南 | 各类业务的操作指引和技术指导 |

### 核心准则要点

注册会计师审计准则强调以风险导向审计为核心方法论，要求注册会计师在审计过程中：了解被审计单位及其环境（包括内部控制），评估重大错报风险，设计和实施进一步审计程序以应对评估的风险，获取充分适当的审计证据，最终对财务报表是否在所有重大方面按照适用的财务报告编制基础编制发表审计意见。

审计报告类型包括：无保留意见、保留意见、否定意见和无法表示意见四种。

## 四、中国内部审计准则

### 概述

中国内部审计准则由中国内部审计协会制定发布，适用于各类组织的内部审计机构、内部审计人员及其从事的内部审计活动。准则体系包含基本准则、具体准则和实务指南三个层级。

### 基本准则要点

**一般准则**：要求根据组织规模与治理结构设立内部审计机构并配备人员；建立质量控制机制；审计人员需具备专业学识并通过持续教育维持胜任力；保持独立性与客观性，严禁介入被审计单位实际经营。

**作业准则**：要求在审计过程中充分考量重要性与潜在风险；制定审计计划并报批后执行；实施前向被审计单位送达通知书；深入调查并测试经营活动及内部控制的有效性；采用多种方法获取充分且可靠的审计证据；将证据、结论及建议详实记录于工作底稿。

**报告准则**：审计结束后须出具客观、准确且清晰的审计报告；报告需包含审计目的、范围、结论及被审计方意见；建立审核制度由负责人审查证据与结论；要求开展后续审计以确保建议落实。

### 内部审计职业道德规范

内部审计人员应遵守以下职业道德：严守准则及协会各项规定；秉持正直、独立、客观与勤勉；保持廉洁；保持谨慎，仅在胜任范围内开展工作；诚实服务、恪守忠诚；严格保密；真实披露所有重要事项；持续参与后续教育。
