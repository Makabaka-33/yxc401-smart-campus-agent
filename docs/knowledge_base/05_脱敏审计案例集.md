# 脱敏审计案例集

本文档收录2个经过脱敏处理的审计案例，供学习研讨使用。所有单位名称、人员姓名和具体金额均为虚构。

## 案例一：某市财政局预算执行审计——内部控制缺陷

### 一、背景信息

2025年，某省审计厅对该省下辖的A市2024年度预算执行情况进行了审计。A市下辖12个乡镇，年度一般公共预算收支规模约50亿元。

### 二、审计发现

**（一）资金审批流程存在重大漏洞**

审计发现，A市财政局在2024年度有23笔大额资金拨付（单笔金额50万元以上）缺少分管领导签字审批环节，涉及金额合计1,850万元。经进一步核查，其中5笔共计320万元的资金拨付对象为同一民营企业"恒达公司"，且拨款用途均为"信息化建设服务费"。

**（二）合同签订程序不规范**

审计组延伸调查了A市财政局与恒达公司签订的5份服务合同。发现以下问题：

- 5份合同均未经过政府采购程序，直接采用单一来源方式
- 合同金额从50万元至80万元不等，均在公开招标限额以下
- 合同中未约定验收标准和付款条件
- 实际交付的信息化系统存在多处功能缺失

**（三）关键岗位人员关联关系**

审计发现，恒达公司的法定代表人张某与A市财政局原副局长李某存在亲属关系。李某已于2024年6月调离财政局，但在其任职期间（2023年1月至2024年5月），上述5笔资金拨付均由其主导推进。

### 三、审计分析

审计组运用以下审计方法进行了深入分析：

1. **数据分析**：导出财政一体化系统中的资金拨付数据，按金额排序筛查大额异常拨付
2. **穿行测试**：选取样本跟踪资金从申请、审批到拨付的完整流程
3. **关联分析**：通过工商登记信息查询，发现供应商与关键岗位人员的关联关系
4. **实地核查**：到恒达公司实地查看交付的信息化系统运行情况

### 四、审计结论与建议

**审计结论**：A市财政局在资金审批、政府采购和廉政建设方面存在内部控制重大缺陷，违反了相关财经法规。

**审计建议**：

1. 责成A市财政局完善大额资金审批制度，严格执行分级审批程序
2. 规范政府采购行为，杜绝规避招标行为
3. 建立健全利益冲突回避制度
4. 将相关线索移送纪检监察机关进一步调查处理

### 五、案例启示

本案例展示了内部控制缺陷如何导致财政资金损失风险。审计人员应保持职业怀疑，善于运用数据分析技术发现异常模式，同时关注关键岗位人员的关联关系。

## 案例二：某高校科研经费审计——虚假报销与资产管理问题

### 一、背景信息

2025年，某高校内部审计处对本校2023-2024年度科研经费管理使用情况进行了专项审计。该校年度科研经费总量约2亿元，涵盖纵向课题和横向课题。

### 二、审计发现

**（一）差旅费虚假报销**

审计组通过数据分析发现，某重点实验室负责人王某在2023年9月至2024年3月期间，以参加学术会议为由报销差旅费12次，累计金额8.6万元。经核实：

- 其中6次会议的举办地点为同一城市，且会议期间该负责人仍在校内参加教学
- 4张住宿发票显示为同一家酒店，但住宿天数与实际会议时间不符
- 部分交通票据时间与会议日期不一致

**（二）设备采购管理混乱**

审计发现该实验室在2023-2024年度使用科研经费采购仪器设备共15台（套），总金额约180万元。存在以下问题：

- 3台设备（价值45万元）购置后一直未安装使用，存放于仓库
- 5台设备的资产卡片信息与实际不符（型号、存放地点错误）
- 2台相同型号的分析仪器（单价28万元）在已有闲置设备的情况下重复购置
- 部分设备的验收报告缺少技术参数检测记录

**（三）外协经费管理失控**

该实验室在2024年度与3家外部单位签订科研合作协议，外拨经费合计120万元。审计发现：

- 2家合作单位实际为同一自然人控制的不同公司
- 外协合同中未明确具体工作量和成果交付标准
- 合作单位提交的阶段性成果报告存在明显抄袭痕迹

### 三、审计方法

1. **数据分析**：将人事考勤数据与差旅报销数据进行交叉比对
2. **实地盘点**：对照固定资产台账逐一核实设备实物
3. **合同审查**：逐份审查外协合同的签订程序和履行情况
4. **成果验证**：请校外同行专家对外协成果进行专业评审

### 四、审计结论与建议

**审计结论**：该高校在科研经费管理方面存在虚假报销、设备资产管理混乱和外协经费失控等问题，涉及科研经费使用效益低下和违规使用风险。

**审计建议**：

1. 完善科研经费报销审核机制，加强财务部门与人事部门的数据交叉验证
2. 建立科研设备全生命周期管理制度，定期开展资产清查
3. 严格外协经费审批程序，建立外协单位资质审查和成果验收机制
4. 对违规使用的科研经费予以追回，对相关责任人按规定处理

### 五、案例启示

本案例反映了高校科研经费管理中的典型风险。内部审计应关注"人、财、物"三方面的匹配关系，利用信息化手段加强数据比对分析，提高发现问题的精准度。同时，科研诚信建设需要从制度层面加强约束。
