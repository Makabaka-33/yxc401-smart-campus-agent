# 审计学基础课程说明与公开课资料

## 一、审计学通论（中国大学MOOC）

### 课程概况

审计学通论是南京审计大学面向全校非审计专业本科生开设的通识教育课程，已在中国大学MOOC平台上线，供全国学习者免费学习。

- **课程平台**：中国大学MOOC（icourse163.org）
- **课程链接**：https://www.icourse163.org/course/NAU-1206687835
- **主讲教师**：和秀星（教授）
- **教学团队**：李兆东（教授）、祝遵宏（教授）、陈卓（副教授）、周芳（副教授）、南永清、靳振忠、陆燕燕、潘玉志、鲁於、孙红莉、赵琛、袁璐、王晓丹等

### 课程目标

本课程旨在使学习者系统掌握审计理论框架、程序准则，熟悉政府审计、内部审计和社会审计三大审计主体的发展动态，并具备运用专业方法收集审计证据、编制审计工作底稿及出具审计报告的实务操作技能。

### 教学大纲

课程包含十个核心模块，每章均配有单元测验与作业：

| 章节 | 主题 | 主要内容 |
|------|------|---------|
| 第一章 | 基本理论 | 审计的起源、本质、职能、目标与分类 |
| 第二章 | 规范体系 | 审计标准、审计准则及职业道德规范 |
| 第三章 | 组织与人员 | 政府审计、内部审计及会计师事务所的体制架构 |
| 第四章 | 审计步骤 | 基本审计流程与三大主体的实践步骤 |
| 第五章 | 证据与底稿 | 审计证据的获取、鉴定及工作底稿的编制 |
| 第六章 | 模式与方法 | 审计模式的历史演变及具体审计技术手段 |
| 第七章 | 审计报告 | 审计报告的种类与撰写规范 |
| 第八章 | 政府审计 | 我国政府审计的现状与核心业务 |
| 第九章 | 内部审计 | 内部审计的职责权限与主要内容 |
| 第十章 | 社会审计 | 注册会计师审计的发展与业务框架 |

## 三、核心教材参考

郑石桥教授主编的《审计基础理论》（第二版，中国人民大学出版社2021年版）是南京审计大学审计学专业的基础理论教材，系统阐述了审计的基本概念、理论框架和方法体系，适合作为审计学入门和进阶学习的核心参考书。
