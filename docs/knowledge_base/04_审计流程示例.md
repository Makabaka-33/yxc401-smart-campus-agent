# 审计流程示例

本文档以一个虚构的"ABC市本级2025年度预算执行审计"为例，展示审计全流程。

## 一、审计计划阶段

### 1.1 审计项目立项

| 项目 | 内容 |
|------|------|
| 项目名称 | ABC市本级2025年度预算执行审计 |
| 立项依据 | 年度审计项目计划、上级审计机关部署 |
| 审计目标 | 评价预算执行的真实性、合法性和效益性 |
| 审计范围 | 市财政局及5个重点预算单位 |
| 审计期间 | 2025年1月1日至12月31日 |
| 审计组组成 | 组长1人、主审1人、审计人员4人 |
| 预计时间 | 2026年3月1日至5月31日 |

### 1.2 审前调查

审计组在实施审计前进行审前调查，了解被审计单位基本情况：

- 收集被审计单位的组织架构、职能职责、内部控制制度
- 了解被审计单位的财务管理体系和信息系统
- 收集以前年度审计报告和整改情况
- 分析宏观经济环境和行业特点对被审计单位的影响

### 1.3 编制审计实施方案

**审计重点**：

1. 预算编制是否科学、合理、完整
2. 预算执行是否严格按照批复执行
3. 重大支出项目的合规性和效益性
4. 政府采购和招投标程序的规范性
5. 国有资产管理情况

**审计方法**：查阅文件资料、数据分析、实地调查、访谈座谈、抽样审计

## 二、风险评估阶段

### 2.1 识别重大错报风险

| 风险领域 | 风险描述 | 风险等级 | 应对措施 |
|---------|---------|---------|---------|
| 预算编制 | 预算编制不够细化，存在虚增虚减风险 | 中 | 重点审查预算编制依据和测算过程 |
| 资金拨付 | 资金拨付不及时或超预算拨款 | 高 | 逐月核对拨付数据与预算指标 |
| 政府采购 | 规避公开招标、化整为零 | 高 | 筛查同类采购合并金额是否超标 |
| 资产管理 | 资产账实不符、闲置浪费 | 中 | 实地盘点与账面核对 |
| 三公经费 | 超标准接待、公车私用 | 中 | 抽查报销凭证和审批手续 |

### 2.2 内部控制评价

对市财政局的内部控制制度进行了解和测试：

- **控制环境**：评价组织架构、权责分配、人力资源政策
- **风险评估机制**：是否建立了风险识别和应对流程
- **控制活动**：审批、授权、核对、复核等控制措施的设计与执行
- **信息与沟通**：财务信息系统可靠性、内部沟通机制
- **监督机制**：内部审计制度运行、自我评估开展情况

## 三、审计证据阶段

### 3.1 审计证据获取方法

| 证据类型 | 获取方法 | 示例 |
|---------|---------|------|
| 实物证据 | 检查、观察、盘点 | 固定资产实地盘点表 |
| 书面证据 | 检查记录或文件 | 预算批复文件、合同、发票 |
| 口头证据 | 询问、访谈 | 与财务负责人的访谈记录 |
| 环境证据 | 观察、分析 | 内部控制运行情况的观察 |
| 分析性证据 | 分析程序 | 预算执行率趋势分析 |

### 3.2 审计工作底稿示例

**审计事项：政府采购合规性审查**

| 项目 | 内容 |
|------|------|
| 审计事项 | 办公设备采购项目合规性 |
| 被审计单位 | ABC市教育局 |
| 索引号 | E-2025-003 |
| 编制日期 | 2026年3月20日 |
| 编制人 | 张某某 |

**审计过程记录**：

经查，ABC市教育局于2025年6月分3次向同一供应商采购办公电脑共计45台，每次采购金额分别为28万元、26万元、27万元，合计81万元。根据ABC市政府采购限额标准，单项或批量采购金额达到50万元以上的货物类项目应当采用公开招标方式。

**审计发现**：该单位将批量采购拆分为多次小额采购，涉嫌规避公开招标。

**审计结论**：上述行为违反了《政府采购法》第二十八条"采购人不得将应当以公开招标方式采购的货物或者服务化整为零"的规定。

## 四、审计报告阶段

### 4.1 审计报告结构

审计报告一般包括以下部分：

1. **标题**：关于ABC市本级2025年度预算执行的审计报告
2. **文号**：X审报〔2026〕X号
3. **主送单位**：ABC市人民政府
4. **前言**：说明审计依据、审计范围、审计时间等
5. **被审计单位基本情况**
6. **审计评价意见**
7. **审计发现的主要问题**
8. **审计处理意见和建议**
9. **附件**

### 4.2 审计报告示例（节选）

**关于ABC市本级2025年度预算执行的审计报告**（节选）

根据《中华人民共和国审计法》第十六条的规定，我厅（局）派出审计组，自2026年3月1日至5月31日，对ABC市本级2025年度预算执行情况进行了审计。现将审计结果报告如下：

**一、基本情况**

ABC市2025年度一般公共预算收入完成XX亿元，支出完成XX亿元……

**二、审计评价**

审计结果表明，ABC市财政局及相关部门能够认真贯彻落实国家财政政策，预算执行总体规范……

**三、审计发现的主要问题**

（一）部分预算单位存在化整为零规避公开招标问题。审计抽查发现，市教育局将批量81万元的办公设备采购拆分为3次，分别以28万元、26万元、27万元实施采购，未执行公开招标程序。

（二）部分专项资金结转结余较大。截至2025年底，有3个专项资金结转结余超过年初预算的30%……

**四、审计处理意见和建议**

（一）责令市教育局对规避公开招标问题进行整改，完善采购管理制度。

（二）建议市财政局加强对预算单位结转结余资金的清理和统筹使用。
