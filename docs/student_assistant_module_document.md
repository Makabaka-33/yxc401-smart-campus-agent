# 学生助手模块需求与功能文档

- 版本：v0.2
- 日期：2026-07-09
- 项目：智启校园教学管智能体
- 模块：学生助手
- 学校场景：南京审计大学，突出审计学习、课程资料管理与学习全过程支持

## 1. 模块定位

学生助手是“智启校园教学管智能体”面向学生学习全过程的核心入口。模块不只提供普通问答，而是围绕课前预习、课堂资料理解、课后复习、考试检测、审计案例实训和个人知识沉淀形成完整闭环。

当前产品形态以类 Qwen/DeepL 的网页端交互为基础：上方保留 API 服务状态与信息门户登录，中间为主对话框，下方提供常用能力入口，并在翻译、思维导图、知识库等高频功能上形成独立工作台。

## 2. 建设目标

1. 建立学生学习资料的统一入口，支持上传、查看、下载、检索和长期保存。
2. 提供面向审计学习的 AI 辅助能力，包括审计概念解释、审计流程梳理、审计证据链分析、练习检测和案例实训。
3. 支持文档翻译、即时翻译、双语总结，帮助学生阅读英文教材、论文、准则和案例材料。
4. 支持基于课程资料生成思维导图，并允许学生继续手动绘制、修改和保存。
5. 形成“上传资料 -> 建立知识库 -> 对话学习 -> 生成产物 -> 加入知识库”的学习闭环。

## 3. 用户需求

### 3.1 学习资料处理需求

学生需要把课件、教材、论文、案例、Excel 数据、照片等资料集中管理，避免资料分散在聊天记录、文件夹和课程群中。系统应支持历史文件查看、下载、在线预览和知识库检索。

### 3.2 翻译与双语学习需求

审计课程中常涉及英文论文、国际审计准则、英文案例和术语材料。学生需要即时翻译文本，也需要上传 PDF、Word、Markdown、TXT 等文档后导出中文译文，并进一步生成中英双语要点总结。

### 3.3 知识结构化需求

学生需要把大段课程内容转化为可复习的结构，例如思维导图、章节大纲、复习路径和知识点清单。系统应支持 AI 自动生成，也支持学生在画布上继续手动补充。

### 3.4 练习检测需求

学生需要根据上传资料或当前主题生成练习题，覆盖选择题、判断题、简答题、案例分析题，并提供答案、解析和知识点标签。

### 3.5 审计专业学习需求

南京审计大学场景下，学生助手需要体现审计特色，重点覆盖审计基础、政府审计、内部审计、社会审计、审计法规准则、审计风险模型、审计证据、审计程序、审计报告、智能审计数据分析等内容。

## 4. 当前功能设计

### 4.1 首页与入口

系统首页标题为“智启校园教学管智能体”，下设三个入口：

- 学习助手：对应学生助手模块，聚焦学习全过程。
- 教学助手：面向教师备课、出题、教学设计。
- 学生生活助手：面向校园事务、流程咨询、信息门户。

进入学习助手后，二级页面左上角显示“学生助手”，右上角显示 API 服务状态和“登录信息门户”入口。

### 4.2 主对话框

主对话框用于普通学习问答和指令输入。对话框内保留：

- “+”按钮：悬浮后展示上传文件和更多工具。
- 新对话：清空当前上下文，开始新会话。
- 发送按钮：提交问题。

对话框内已去除“报告”按钮，避免功能入口过多。

### 4.3 “+”工具菜单

鼠标悬浮或点击“+”后显示工具菜单：

- 文件和图片：上传课程资料。
- 常用语：打开常用指令弹窗，不同模块显示不同常用语。
- 插件：灰色展示，标注“内测中”。
- 技能：灰色展示，标注“内测中”。
- 联网搜索：用于后续联网资料检索。

### 4.4 快捷功能区

对话框下方保留四个主要功能：

- 深度研究：用于需要多步分析、长时间推理的学习问题。
- 翻译：进入翻译工作台，支持即时翻译和文档翻译。
- 思维导图：进入思维导图工作台，支持 AI 生成和手动绘制。
- 练习检测：根据主题或知识库资料生成题目、答案和解析。

知识库建设作为独立大入口展示，视觉优先级高于普通快捷功能。

### 4.5 翻译工作台

点击“翻译”后：

- 欢迎语、快捷功能区、知识库入口和下方资料面板暂时隐藏。
- “翻译”功能块移动到对话框左侧下方，并显示“×”退出按钮。
- 下方展示两个子功能：即时翻译、文档翻译。

即时翻译：

- 参考 DeepL 网页端形式。
- 上方支持源语言、目标语言与切换按钮。
- 下方为左右双栏，左侧输入原文，右侧显示译文。

文档翻译：

- 参考 PDFMathTranslate 类项目的文档翻译流程。
- 支持上传文件并导出中文 DOCX 译文。
- 支持生成“双语要点总结”。
- 支持将译文或总结加入知识库。

### 4.6 思维导图工作台

点击“思维导图”后：

- 欢迎语、快捷功能区、知识库入口和下方资料面板暂时隐藏。
- “思维导图”功能块移动到对话框左侧下方，并显示“×”退出按钮。
- 展示专业画布界面，当前实现为前端 SVG 画布，后续可接入 wanglin2/mind-map 或 XMind。

支持能力：

- 输入中心主题。
- AI 生成课程思维导图。
- 手动添加、删除节点。
- 保存生成结果或手绘结果到知识库。

### 4.7 知识库建设

知识库是学生助手最核心的长期资产管理区，支持：

- 历史上传文件展示。
- Word、PDF、Excel、文本、图片等常见资料类型管理。
- 在线查看或下载历史文件。
- 历史生成内容展示，包括思维导图、文件大纲、练习检测等。
- 对生成内容提供“加入知识库”操作。
- 一键导入课程表，形成个人课程记录。

### 4.8 最近信息面板

页面下方保留四类辅助信息：

- 资料状态：显示当前模型、文档数、片段数等状态。
- 最近资料：显示最近上传的学习资料，并支持查看或下载。
- 最近对话：显示历史对话记录。
- 最近调用：显示近期模型或接口调用状态。

## 5. 审计学习特色功能

学生助手应围绕南京审计大学的专业特色形成差异化能力：

1. 审计概念学习：解释审计目标、审计证据、重要性、审计风险、内部控制等核心概念。
2. 三类审计对比：政府审计、内部审计、社会审计的主体、对象、依据、流程和报告对象对比。
3. 审计流程训练：从审计计划、风险评估、控制测试、实质性程序、证据获取到审计报告形成完整学习路径。
4. 审计案例分析：根据案例识别风险点、审计目标、审计程序和证据清单。
5. 智能审计数据分析：支持 Excel/CSV 数据，用于重复报销、异常金额、供应商集中度等演示级检查。
6. 审计术语翻译：在英文资料翻译中保留 audit evidence、materiality、internal control 等中英术语对照。

## 6. 关键业务流程

### 6.1 知识库闭环

上传课程资料 -> 系统解析并入库 -> 学生基于资料提问 -> AI 引用知识库回答 -> 生成思维导图/练习/大纲 -> 询问是否加入知识库 -> 形成长期学习资产。

### 6.2 翻译闭环

输入文本或上传文档 -> AI 翻译 -> 导出中文 DOCX -> 生成中英双语要点总结 -> 加入知识库 -> 后续可继续问答、复习和生成练习。

### 6.3 思维导图闭环

输入主题或选择资料 -> AI 生成思维导图 -> 学生在画布继续编辑 -> 保存为历史生成内容 -> 加入知识库 -> 后续复习或导出。

### 6.4 练习检测闭环

选择主题或使用知识库资料 -> 生成练习题 -> 查看答案与解析 -> 标记薄弱知识点 -> 后续生成复习计划或错题本。

## 7. 非功能需求

### 7.1 易用性

界面应减少堆叠卡片，优先采用清晰的工作台式交互。高频功能要有明确入口，进入专项功能后应自动隐藏无关内容，降低干扰。

### 7.2 可追溯性

所有基于知识库的回答、总结和生成内容应尽量保留来源资料、生成时间和历史记录，避免学习内容不可追溯。

### 7.3 可扩展性

翻译、知识库、思维导图、练习检测应保持模块化，便于后续替换为更专业的 OCR、向量数据库、PDF 版式翻译、simple-mind-map/XMind 等能力。

### 7.4 数据安全

学生上传资料默认应仅本人可见。涉及审计案例、课程资料、个人课程表和校园账号信息时，需要权限控制和脱敏机制。

## 9. 未来改进方向

### 9.1 翻译能力增强

- 接入更完整的 PDFMathTranslate 或同类能力，支持 PDF 原版式保留。
- 支持 PPTX、扫描版 PDF、图片 OCR。
- 支持中英对照排版、段落级重新翻译、术语表和翻译记忆。
- 支持翻译质量评分和人工修订记录。

### 9.2 知识库能力增强

- 从当前轻量检索升级为向量检索 + 关键词检索 + 重排。
- 支持课程级知识库、个人知识库、班级共享知识库。
- 增加资料版本管理、删除/重新索引、标签分类。
- 强化引用展示，回答中明确标注来源文件、页码或片段。

### 9.3 思维导图能力增强

- 正式接入 wanglin2/mind-map 或 XMind 导入导出能力。
- 支持节点拖拽、折叠、颜色标记、备注、关系线。
- 支持导出 PNG、SVG、Markdown、XMind。
- 支持从知识库自动生成多层级课程图谱。

### 9.4 学习评测增强

- 建立错题本和薄弱知识点画像。
- 支持按考试时间生成复习计划。
- 支持间隔重复复习提醒。
- 支持阶段学习报告，包括资料阅读量、练习正确率、薄弱章节和建议任务。

### 9.5 审计专业能力增强

- 增加审计案例库和脱敏实训数据集。
- 支持审计证据链可视化。
- 支持审计流程模拟训练。
- 支持 Excel 数据异常检测、供应商集中度分析、重复报销识别等智能审计演示。

### 9.6 校园集成增强

- 接入南京审计大学统一身份认证。
- 接入课程表、课程平台、信息门户和教师资料上传入口。
- 支持课程资料授权共享。
- 支持校内通知、教务安排和课程资源的统一检索。

## 10. 验收建议

1. 学生可以进入学生助手页面，并看到 API 服务、登录信息门户、主对话框和核心功能入口。
2. 对话框内不再出现“报告”按钮。
3. 点击“翻译”后进入专项工作台，欢迎语和下方功能区隐藏，显示即时翻译和文档翻译。
4. 文档翻译完成后可以下载译文，并生成双语要点总结。
5. 点击“思维导图”后进入专项工作台，可以 AI 生成或手动添加节点。
6. 上传资料可以进入知识库，并在历史资料中查看或下载。
7. 生成的思维导图、文件大纲、练习检测等内容可以加入知识库。
8. 一键导入课程表后，课程记录可以在知识库中展示。

## 11. 结论

学生助手模块的核心价值在于把分散的学习资料、AI 对话、翻译、思维导图、练习检测和知识库沉淀整合到一个统一入口中。对于南京审计大学场景，后续应继续强化审计专业内容、审计案例实训、审计数据分析和校内系统集成，使其从通用学习助手升级为具有学校特色的审计学习智能体。
