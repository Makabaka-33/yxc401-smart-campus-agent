### 4. 完成四个固定业务模块

#### 我的事务

- 展示事项名称、当前状态、材料完成度、下一步、负责部门、截止时间和操作按钮。
- 支持打开事务详情并勾选材料或步骤。
- 办理进度保存在浏览器 `localStorage`。
- 示例包括奖学金、成绩单与证明、校园卡、四六级和论文开题等。

#### 近期重点

- 根据本科生或研究生身份展示不同重点事项。
- 展示发布日期或截止日期，并计算剩余天数。
- 明确区分真实日期与答辩演示日期。
- 支持加入或移除本地待办。

#### 校园服务

- 提供教学信息系统、研究生院、图书馆、校园导航、校园卡、证明打印和宿舍服务等入口。
- 服务说明会根据本科生或研究生身份变化。
- 无法核验完整流程的服务标记为“待学校确认”。

#### 校园消息速览

- 不再只提供学校或部门首页链接。
- 新增 `/api/affairs/notices` 聚合接口，读取学校官网中的具体通知文章。
- 本科生优先匹配教务处、学生工作处和图书馆。
- 研究生优先匹配研究生院，同时保留与研究生有关的教务和图书馆通知。
- 根据身份、年级、标题关键词和发布时间过滤内容。
- 过滤不匹配年级、招生复试、教师工作、党建会议等低相关资讯。
- 按发布日期倒序展示标题、摘要、部门、发布时间、匹配原因和截止状态。
- 所有消息卡片直达具体 `page.htm` 通知文章。
- 官网超时或网页结构变化时，返回已核验的文章级回退数据，而不是部门首页。
- 设置 15 分钟缓存，并提供“刷新资讯”按钮。

### 5. 增加事务 Agent 与本地交互

- 搜索框会先检索当前身份的结构化事务、通知和服务。
- 未命中时调用现有 `/api/chat` 事务模式。
- 请求中携带学段、年级和学院等身份上下文。
- 保留最近问题，并支持快捷问题再次询问。
- 对公开信息缺失的学生证、宿舍报修等流程明确提示“待学校确认”。

## 五、数据可信度规则

- **官方已核验**：来自本年度官方具体通知，链接日期、发布时间和事项时间线一致。
- **官网实时**：由资讯聚合接口实时读取并经过身份相关性过滤。
- **往年规律预估**：参考往年官方通知或国家考试规律，只展示预计月份或时间区间。
- **待官方通知**：本年度尚无适用通知，不显示精确日期和倒计时。
- **演示模拟**：只用于答辩档案、办理进度和交互状态，不包装未经发布的截止日期。
- **待学校确认**：公开网页没有完整披露，需要校内系统或业务部门确认。

本版本不会把浏览器中的勾选结果写入学校系统，也不代表真实审批结果。

2026-07-15 完成时间可信度修正：删除下半年四六级、开题、奖学金和培养计划等未经发布事项的虚构精确日期；新增 `expectedWindow`、`timeBasis` 和多官方来源字段。后端会拒绝未来发布、链接年月与发布日期冲突、截止日早于发布日期的资讯。

2026-07-15 增加正文级抓取与结构化解析：官网列表发现具体文章后，后端继续访问官方正文，提取正文摘要、适用身份、时间节点、明确截止日期、联系电话、关键要求、办理入口、附件及章节。前端消息卡片增加“查看正文解析”，并显示实际完成正文解析的篇数。正文抓取严格使用官方域名白名单、每来源数量限制、并发限制、响应大小限制和超时。
